Projeto A3 - Teoria da Computação e Compiladores
Nome do projeto - Linguagem de Teste (TL)
Tecnologias utilizadas: Java (JavaSE-21), JavaCC.

O projeto principal referente a UC (arquivo contendo a definição dos Tokens (léxica), regras sintáticas e semânticas) está em: linguagem-de-teste>src>main>javacc.
Há um arquivo .txt em linguagem-de-teste>src>main>java>dev>napoleon contendo alguns exemplos de como a linguagem funciona. Para utilizar este arquivo é preciso dar "run" na classe (Main.java) que está no mesmo diretório do arquivo .txt.

Plugins necessários (para rodar no VSCode): logo abaixo de "build" e antes da abertura de "pluginsManagement", no arquivo pom.
